# Workflow files to install by hand

The Claude GitHub App cannot write `.github/workflows/`. Dvir copies these there (needs the `APIFY_TOKEN` repo secret, already set):

- `apify-push.yml` (copy over the one in `.github/workflows/`): manual `workflow_dispatch` with inputs `actor` and `allow_live` (default false). Allow-list: the 3 newer actors and `all-new`; the 4 older live actors (`bulk-dns-email-auth-checker`, `sitemap-url-extractor`, `bulk-domain-availability-checker`, `domain-checkup-report`) only with `allow_live=true`. Steps: pytest; `tools/apify_guard.py --snapshot` records isPublic and pricing (GET only); `apify push`; `tools/apify_memory.py` sets `defaultRunOptions.memoryMbytes = 256` (PUT, that field only); `tools/apify_guard.py --before` GETs again and fails only if the pricing changed or memory is not 256 (a public, already-priced actor with unchanged pricing passes); summary with id, name and build, plus the line for `docs/requests/DOM-TO-GAVRIEL.md` (job summary and artifact). Never publishes, never sets prices, never prints the token. Each run needs Dvir's OK via Gavriel.
- `apify-usage.yml`: daily `0 6 * * *` plus manual; `tools/apify_usage.py` writes `usage/DATE.json` and day-over-day deltas to the branch `apify-usage`. GET-only; nothing is written if a call fails.
