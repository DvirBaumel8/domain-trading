# AI Visibility Check

Private repo for the AI Visibility Check website (operator: Dvir Baumel). Not the public domain-trading repo.

The site is a small Python server (`site/server.py`) plus static pages. Deploy is a Render **free** web service; see `render.yaml`. Payment links stay empty until Polar is connected. Orders: set `ORDERS_REPO` + `ORDERS_GITHUB_TOKEN` (private repo; unset = local `private-orders/`), `ORDER_ALERT_WEBHOOK_URL`, `POLAR_WEBHOOK_SECRET`; Polar webhook URL is `/api/polar/webhook` (event `order.paid`). Automatic delivery (off by default): `AIVIS_AUTORUN=1` + `AIVIS_ORDER_CAP_USD` (required, per-order spend cap) + `AIVIS_ALLOW_PAID=1` + the 4 engine keys; a paid order then builds its report in the background and publishes it at the private link `/r/<token>` (status page `/status/<token>`). With autorun off the order is only marked `queued`. Operator smoke test (real calls, a few cents, never in CI): `python -m aivis smoke --engine all`. Tests: `python3 -m unittest discover -s tests`.
