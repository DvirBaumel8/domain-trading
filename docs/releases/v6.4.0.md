# Release v6.4.0 (4 Nov 2026)

**Contract:** 6.4.0 (MINOR, migration `1769500000000_v6-4-0.sql`). CR-101: the shortlist stops serving names a bot already threw away (46% of the 3 Nov list).

- **What changed:**
  - **`POST /auctions/kills`** (WRITE or bots; `Idempotency-Key`; 1..2,000 rows). Each row is `{domain (.com), kill_stage, kill_detail?, price_cents_at_kill?, data_date_at_kill, run_id, killed_at, supersedes?}`.
    - `kill_stage` is one of `meaning_shape`, `tier_a`, `tier_b`, `card`, `prior_exclude`, `declined`, `hold`, `other`, `revoked`.
    - An `@` in `kill_detail` refuses the whole request (422 `NO_PII`). Other bad rows are rejected per row.
    - A duplicate (same domain, stage, data date) counts in `duplicate_n` and stores nothing.
    - The table is append-only. A wrong kill is undone with a `revoked` row whose `supersedes` is the kill's id (same domain).
    - Normal `DB_SIZE_HIGH` guard.
  - **`GET /auctions/kills`** (READ, bots, WRITE; data token 403): `?domain&since&limit&offset`, newest first, `total`, `revoked_by` per row.
  - **`GET /auctions/shortlist`:** a name with an active kill is left out, unless:
    - the kill is `tier_a`, `tier_b` or `card` with a price, and today's price is at most half of it (`reshow_reason: "price_halved"`); or
    - the kill is older than `settings.shortlist_kill_ttl_days` (90; `"ttl"`).

    A name that has several active kills is left out if any one of them blocks it. New fields:
    - `rows[].prior_kill` (`{kill_stage, killed_at, price_cents_at_kill, reshow_reason}`, or null);
    - `prior_kill_excluded_n`.

    `total` and the pages count after the exclusion. Stored shortlist rows are never deleted (paper, funnel and replay are unchanged).
  - **`GET /auctions/funnel`:** `shortlisted.prior_kill_excluded`.
- **Impact on Gavriel and the Buyer:**
  - DOM Architect seeds the prior kills after the deploy (the CR's ask 6: `prior-exclude.txt` plus the `kills.csv` rows).
  - The Buyer posts its kills at the end of every run and records the served and skipped counts in each run pack (`docs/bot-logic/04-buyer-shortlist-to-card.md`).
- **How to test it:**
  1. `POST /auctions/kills` with one row.
  2. `GET /auctions/shortlist?date=<today>`: the name is gone and `prior_kill_excluded_n` is 1.
  3. Post a `revoked` row with `supersedes`: the name is back.
- **Deploy status:** pushed to `main` with tag `v6.4.0`; the Mac host deploys after CI.
- **Lessons:** the contract-doc and test-evidence tests caught missing docs the moment the routes were added. Regenerate the evidence before the last full run, not after it.
