**Contract:** 7.2.0, MINOR (CR-116).

- **What changed:** Google Web Risk in `/check`; new reads of the registrars, Afternic, GoDaddy Auctions and one USPTO record. Nothing can bid, buy or change anything, and a test guards that. A missing key or a failing source is always an error.

- **Impact on Gavriel:** add the keys in Render as they are made; `/health` shows which are set.
- **How to test it:** `/check` shows `web_risk`; `/registrar-status` lists the five names.
- **Deploy status:** see `docs/requests/DOM-TO-GAVRIEL.md`.
- **Lessons:** read the official documentation before accepting a key list: two of the keys can spend or change listings, and GoDaddy has no call that lists our bids.
