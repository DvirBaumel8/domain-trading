# Release v7.0.0 (23 Nov 2026)

**Contract:** 7.0.0, MAJOR. Dvir, 23 Nov 2026: the app is stateless, has no database, and keeps only the domains owned and the money spent, in this repo.

- **What changed:** Postgres, the 102 migrations, the job queue and all modules built on them are gone (40,700 lines of source to about 850). `data/state.json` is the state. CI enforces the founder rules on it.
- **Kept:** `GET /health/ping`, `/health`, `/check`, `/portfolio`, `/portfolio/{domain}`, `/ledger`, `/report`.
- **Gone:** everything else of 6.x, all writes included. 404 `NOT_FOUND`.
- **Impact on Gavriel and the bots:** SOPs that call other routes (preflight, shortlist, jobs, exports, kills, kb) stop working. A purchase, cost, renewal or sale is a request with Dvir's approval; DOM commits the row.
- **Data:** 5 domains, 5 purchases, $71.16, taken from this repo's notes because the database is unreachable (Neon quota). To confirm: `docs/internal/gaps.md` S-1, S-2.
- **How to test it:** `GET /health/ping` shows `7.0.0`; `GET /report` with a token shows `domains_owned` 5 and `spent` `$71.16`.
- **Deploy status:** live on Render, `/health/ping` checked 23 Nov 2026 (7.0.0, commit 40d1cdf0). The token routes are closed (401) until `API_TOKENS` is set in Render; whether the Porkbun keys are set there is not checked yet.
- **Lessons:** the state we needed was 5 domains and 5 rows; the system around it cost 102 migrations and two outages on free database quotas. Ask what must be kept before building where to keep it.
