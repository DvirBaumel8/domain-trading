# Release v5.61.0 (27 Oct 2026)

**Contract:** 5.61.0 (MINOR, migration). Also deploys 5.60.0's migration (BUG-053 approval note), whose tag never reached main.

- **What changed:** the Afternic seller API (released by Afternic on 22 Oct 2026) is wired in. Daily step `afternicSync` reads every listing and its 30-day views and leads (no browser, no hand import); `/report` raises `AFTERNIC_DRIFT` / `AFTERNIC_NOT_LISTED` when Afternic differs from our plan. `POST /export/afternic/push` (WRITE) sets Afternic to the plan for the differing names; `dry_run: true` shows the exact diff first. The walk-away is never sent. The scheduled price job still never calls a marketplace. Lease-to-own maximum is 12 months (Dvir, 27 Oct: shorter leases cancel less, NameBio's 290 LTO deals).
- **Impact on Gavriel:** listing changes on Afternic go through the push route (dry run, Dvir's line on the diff, then the real push) instead of the browser; views and leads arrive daily on their own (CR-037 hand import retired).
- **How to test it:** `POST /export/afternic/push {"dry_run":true}`; `GET /report` warnings after the next daily run; `GET /visits` source `afternic`. Tests AFN-1..16, AFN-4b.
- **Deploy:** the Mac host after CI.
- **Lessons:** read the platform's changelog before assuming "no API": Afternic opened one five days before we looked, and the browser workaround had cost hours.
