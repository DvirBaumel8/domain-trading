# Release v2.11.1 (7 Oct 2026)

**Contract:** 2.11.1. PATCH. CR-010 T10-1 follow-up. **Deploy:** see the end.

- **Registry circuit breaker:** after 5 refusals in a row from one RDAP registry within a run, the run stops asking that registry; its remaining lookups are UNKNOWN `RATE_LIMITED` at once, counted in `lookups.rate_limited`, never "not registered". Another registry in the same run is unaffected; a success before the fifth refusal resets the count.
- **Why:** `.biz` refuses every lookup, so a 894-name rerun waited on it for 49 minutes (CR-009 run C). With the breaker it should take a few minutes. Gavriel can measure it with a fourth rescore (T10-1).
- **No migration.**
