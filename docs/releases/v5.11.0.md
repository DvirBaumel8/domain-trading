# Release v5.11.0 (17 Oct 2026)

**Contract:** 5.11.0. CR-062: NameBio data from the free endpoints only, with attribution

- **What changed:** (A) The NameBio source uses only NameBio's free endpoints: `POST api.namebio.com/retailstats`, `/tldstats`, `/verisign` and the free files `/retailstats-download`, `/tldstats-download`, `/verisign-download`. Any other path or host is refused before a request goes out; the paid API is never called. (B) Limits enforced in code and kept across restarts: retailstats and tldstats 4 a minute, verisign 5 calls per 24 h (100 domains a call); a rate-limit answer waits 60 s and retries once. (C) The daily `referenceRefresh` step downloads the files (env URLs, each at most once a day) or, with no RetailStats URL, asks RetailStats for candidate-pool keywords. (D) `GET /selection/namebio` returns placement stats with `source: "namebio_free"`, `attribution`, `attribution_url`, `data_as_of`, `stale`. (E) The step logs rows written, file bytes and DB bytes before/after (R-7). `sources.namebio` is still off; nothing is fetched until Dvir turns it on. Contract: `endpoints.md`, `jobs.md`, `selection.md`.
