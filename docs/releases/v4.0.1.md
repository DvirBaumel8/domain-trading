# Release v4.0.1 (13 Oct 2026)

**Contract:** 4.0.1 (PATCH). Two fixes from Gavriel's 4.0.0 acceptance (CR-051).

- **What changed:**
  - **B-1:** `screening_group` is `null` for a name with no screening pack, in the `/buy` dry run, the 201 and on the domain. It was `passed`. A real buy needs a pack, so a bought name still gets `passed` or `borderline`.
  - **B-2:** `POST /portfolio/{domain}/stats` with `@` in `source` answers 422 `NO_PII` with the message "source must not contain…" and `details.field: "source"`. It used to say "note".
- **How to test it:** a `/buy` dry run on a name with `screening_pack.status: none` shows `screening_group: null`. A stats POST with `source: "a@b.com"` gets 422 naming `source`; nothing is stored.
- **Deploy:** tag v4.0.1; the Mac host deploys it within about 10 minutes of CI passing. Confirm `version: 4.0.1` on `/health`.
