# Release v7.3.0 (24 Nov 2026)

**Contract:** 7.3.0. Daily auction pre-filter with a public shadow log; the budget rules in code

- **What changed:** the daily pre-filter of GoDaddy auctions and closeouts writes to the branch `shadow-log` (`docs/contract/prefilter.md`). `GET /budget` applies the caps: $1,500 with the year-2 renewals and open bids inside, $250 a name, 40 names, $300 for closeouts. The four long names are marked do not renew. Founder rule 5 allows the $300 closeout pilot (Dvir, 24 Nov).
- **Changed from the CR, with Dvir's yes:** auctions need one bid; no maximum or planned price in the public log; open bids and the renewal price are given to `/budget`; final prices by hand; no filter route in the app. **DOM's choice:** the closeout gate (3 endings, 5 years), Spamhaus not called (non-commercial terms), Wayback by addresses within 40 minutes.
- **How to test it:** `/budget?price_cents=2000&fee_cents=20&renewal_cents=2200&source=auction&open_bids=none` answers `unknown` until mineunited.com has a renewal price. Run the workflow `prefilter` by hand after 14:45 UTC and read `runs/DATE.json`.
- **Lessons:** measure the real file before writing a gate (the CR's gates left 125,344 names); a source's terms are part of its check.
