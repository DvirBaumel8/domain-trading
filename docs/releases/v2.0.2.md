# Release v2.0.2 (7 Oct 2026)

**Contract:** 2.0.2. Additive. **Deploy:** live at `https://domain-trading-api.onrender.com`.

## What changed
- Dry-run `POST /buy`: an error thrown after the DOM gates (BUY_HOLD, SCREENING_PACK_REQUIRED, NO_TRANCHE, TRANCHE_SPEND_CAP) were evaluated now carries `would_be_blocked`, `screening_pack` and `advisories` in `error.details`, same shapes as the 200 body. Before, the registrar-step errors lost them.
- Real buys, the dry-run 200 and errors before the gates (approval, validation) are unchanged.

## Affects Gavriel
- Dry-run 409s after the DOM gates now carry the v2 fields.
- With Porkbun at $0 (by policy) for a name that has not been screened, expect 409 `REGISTRAR_FUNDS` with `details.would_be_blocked: "SCREENING_PACK_REQUIRED"` (no screening pack yet). `BUY_HOLD` appears first only for a name screened under settings with the buy hold on.
