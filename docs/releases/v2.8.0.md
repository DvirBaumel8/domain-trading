# Release v2.8.0 (7 Oct 2026)

**Contract:** 2.8.0. Additive (MINOR). CR-007 G-2 source A (drop lists) and G-1 (cohorts, the forward test). This is the last part of CR-007. **Deploy:** live since 2026-10-07 (`GET /health` `version: 2.8.0`; `GET /selection/drop-lists/<unknown>` → 404).

## What changed, and how Gavriel tests each item

| Item | What | How to test it |
|---|---|---|
| **Drop lists** (G-2, AC-6, AC-8) | `POST /selection/drop-lists` (an uploaded deleting list); DOM keeps letters-only 2–3-word `.com` names (the `bt1@v2` split), with a reason for each removed name. The daily step `dropWatch` reads each name's registry status and estimates the drop date. `GET /selection/drop-lists/{name}` and `?drop_from=&drop_to=`. `/report` warns `DROP_FEED_STALE` after 2 days without a new list | Upload a list of 50 names with a digit, a hyphen and a 4-word name among them: each removed with its reason. After the next daily run, statuses and expected drop dates appear |
| **Cohorts** (G-1, AC-1 to AC-5) | `POST /selection/cohorts` with names or a seeded sample of the drop list and 1–3 settings labels. DOM computes features, freezes the decisions before the drop, then the daily step `cohortOutcomes` records the drop outcome and re-registration at 30/60/90 days. `GET /selection/cohorts/{name}` and `/selection/cohorts/report?settings=` with Wilson ranges and the FWD-1 pass line | The round-13 forward names (`fwd13.csv`) as `names` with their expected drop dates; names already past their date are `LATE` |

## Notes
- **Read-only toward the outside:** all lookups are Verisign RDAP, at most 4 at a time, slowing down on refusals, and capped per daily run (3,000 for `dropWatch`, 2,000 for `cohortOutcomes`). A failed lookup is `unknown`, never "free" or "re-registered".
- **Cohort decisions** treat `prior_history` as 1 (every cohort name is about to drop after a registration).
- **Migration:** `1761200000000_v2-8-0.sql` adds seven tables (in the data backup); all are append-only except `cohorts`, whose only allowed change is computing → frozen.
