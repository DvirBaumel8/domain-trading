# Release v7.1.0 (23 Nov 2026)

**Contract:** 7.1.0, MINOR. No route changed.

- **What changed:** who may read is in `data/access.json` (hashes only), so a token is added by a commit and nothing has to be set in Render. About 2,400 redundant files are deleted (tag `archive-2026-11-23` has them), and the manual is rewritten short. CI also checks that the approval records named in `data/state.json` exist.
- **Impact on Gavriel:** send your token's hash (`docs/requests/DOM-TO-GAVRIEL.md` point 1). Bots push only to `docs/requests/`.
- **How to test it:** `GET /health/ping` shows `7.1.0`; `GET /report` with a listed token shows `domains_owned` 5 and `spent` `$71.16`.
- **Deploy status:** the tagged commit never deployed: the `deploy-live` check waited for Render while Render waited for the check. Both notifier workflows are removed, and the next commit carries 7.1.0.
- **Lessons:** a token that needs a person to carry it is a design fault; store the hash, let the owner keep the secret.
