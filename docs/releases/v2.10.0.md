## What changed, and how Gavriel tests each item

| Item | What | How to test it |
|---|---|---|
| **Company document** (T11-14) | `POST /company/document` stores a new version only when the text changes; `GET /company/document/versions` and `/versions/{n}` with a unified diff | Upload `company.md`, then the same text (200, `changed: false`), then an edited one (version 2 with a diff) |
| **Block list** (T11-3, T11-25) | Secrets, DOM token shapes, emails, phones and forbidden terms are refused as `TEXT_BLOCKED` with the category only. `POST /company/forbidden-terms`; reads never show a term | Upload a text with an email: 422 `details.category: "email"`, no echo |
| **Review packet** (T11-15 to T11-17, T11-24) | `POST /reviews/packet` (`preview` stores nothing): the document (in full weekly or first, else the diff), DOM's changes since the last packet, the `/report` numbers without walk-away. Stored exactly as sent | Preview, then a real packet; `GET /reviews/packets/{id}` returns it |
| **Feedback** (T11-18 to T11-20, T11-23) | `POST /reviews/{packet_id}/feedback` (ok with items, or unknown with the reason); items marked `new` / `repeat` (Jaccard ≥ 0.6 on significant words, same category); `GET /reviews/items` (`view=new` hides repeats of rejected items); `POST /reviews/items/{id}/status` | Post the same item text on two packets: the second is `repeat` |
| **Cost** (T11-22) | `GET /reviews/cost`; past $5 in a month, `POST /reviews/packet` → 409 `REVIEW_COST_CAP` | Report `cost_usd` with each feedback |
| **Overdue** | `/report` warning `REVIEW_OVERDUE` after 36 hours without feedback (once any exists) | |
