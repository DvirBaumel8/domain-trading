# Release v3.2.1 (9 Oct 2026)

**Contract:** 3.2.1, PATCH, additive.

**Why:** the first live `POST /posts/schema-check` on 3.2.0 returned `ok: false`. Buffer's live API differs from its published reference:
- `shareMode` is not a field; `mode`, `schedulingType` and `needsApproval` are required;
- `ImageAssetInput` has no `altText`.

The check did its job: no post was sent.

**What changed:** `POST /posts/schema-check` now also returns `types`, Buffer's own definitions of the input types (names and types only, no secrets), so DOM can build the input from the live schema. **3.2.2** fixes the input.

**How to test:** `POST /posts/schema-check` → `types.CreatePostInput.fields`.
