# Release v5.8.0 (16 Oct 2026)

**Contract:** 5.8.0. CR-059 S8 aftermarket import lane (Line 2): `POST /portfolio/import`, the S8 slot reservation, `/report` `lines`

- **What changed:** (A) New `POST /portfolio/import` records a name Dvir bought on a registrar website (GoDaddy, Dynadot, closeout / fixed price / public auction) as a Line 2 (S8) name: the `domains` row (`lane: "S8"`), one `registration` ledger row for the price paid, the evidence row and the listing plan. (B) The caps are in the settings row and change only by migration: $50 per name (`s8_max_price_cents`) and 10 reserved slots (`s8_reserved_slots`). There is no S8 money total (G-86). (C) `GET /report` gains `lines` (per line: names, spend, sales, P&L, committed renewals) and every `per_domain` row has `line` (1 or 2) and `lane`. Migration `1764100000000_v5-8-0.sql`. Contract: `endpoints.md` (S8 import lane, Code index), `reports.md`.
- **Impact on Gavriel:**
  - **Approval.** The import needs Dvir's `approval_ref` naming the domain, at most 72 h old, as at `/buy`. Refusals are 400 `S8_SOURCE_INVALID`, `BACKORDER_SOURCE_REFUSED` (NameJet, SnapNames, DropCatch as source or registrar), `S8_PRICE_CAP` (over $50), 409 `S8_SLOTS_FULL`.
  - **Pricing.** Send `comps_value` (USD; the value the comparable sales support). The BIN is the lowest price-list price at or above it (the list comes from the current `pricing_settings`); above the top open price it gets the top open price ($1,488 on the current list, because $1,988 and $2,488 need LANDER-1 evidence); below the list minimum it gets the minimum ($788). A geo name takes `price_grade` and the grade price instead. `pricing_evidence` is optional.
  - **Registrar.** For `godaddy` and `porkbun` (when enabled) the service reads the expiry from the registrar; for any other registrar (e.g. `dynadot`) the import is manual and `expiry_date` is required. Turn auto-renew off at the registrar (the warning says so).
  - **Slots (behaviour change).** Of the 40 names, 10 are reserved for S8. `POST /buy` is refused (409 `DOMAIN_CAP_REACHED`) once Line 1 holds 30 names; every name held today is Line 1, so if Line 1 already holds more than 30, `/buy` is closed until it falls under 30 (S8 imports still work while fewer than 10 S8 names and fewer than 40 names in all are held).
  - **Report.** `lines[0]` is Line 1, `lines[1]` is Line 2. `pnl` = every ledger row of the line's names (so a sale's commission and fees count); tool and AI cost rows have no name and belong to no line.
- **How to test it:**
  1. `POST /portfolio/import` with `dry_run: true`, `lane: "S8"`, `source: "closeout"`, `registrar: "dynadot"`, `price_paid: 12.5`, `buy_date`, `expiry_date`, `category`, `comps_value: 1200` and an `approval_ref` naming the domain: 200, `s8.bin_cents` 148800, `would_be_blocked: null`, nothing written. Without `approval_ref`: 422 `APPROVAL_INVALID`. With `price_paid: 50.01`: 400 `S8_PRICE_CAP`. With `source: "namejet"`: 400 `BACKORDER_SOURCE_REFUSED`.
  2. `POST /buy` with `dry_run: true` while Line 1 holds 30 names: `would_be_blocked: "DOMAIN_CAP_REACHED"`.
  3. `GET /report`: `lines` with two rows; `per_domain[].line`.
- **Deploy:** migration `1764100000000_v5-8-0.sql` runs on start. Push to `main`, tag `v5.8.0`; it deploys to the Mac host after CI passes (`scripts/local-host/deploy.sh`, DOM). Gavriel confirms the live version on `/health`.
