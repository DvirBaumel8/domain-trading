# Release v5.9.0 (16 Oct 2026)

**Contract:** 5.9.0. CR-060: the S8 import accepts Dvir's approved Buy Now and floor, prices by the S8 ladder, and fits closeouts

- **What changed:** (A) `POST /portfolio/import` takes `bin_override` and `floor_override` (cents), each named in Dvir's `approval_ref.text`. (B) Without an override the BIN is the S8 ladder by name length: up to 8 characters $4,888, 9-12 $3,488, 13+ $2,488 (settings row, migration `1764200000000_v5-9-0.sql`); the floor is 65% of the BIN. `comps_value` is optional evidence. (C) S8 expiry may be up to buy date + 2 years + 30 days. (D) S8 names have no M6/M18 drops; final push and delist stay. S8 BINs are not checked against the Line 1 price list anywhere (founder rule 4 exception for S8, Dvir's CR-060 decision; `gaps.md` G-105). Contract: `endpoints.md` S8 import lane.
- **Impact on Gavriel:**
  - **Overrides.** Send `bin_override: 348800` and `floor_override: 226700` only when Dvir's line names `$3,488` and `$2,267`. Not named: 422 `APPROVAL_INVALID` with `details.override`. Floor above BIN: 422.
  - **Default price.** `comps_value` no longer picks the BIN (5.8.0 rung removed). mineunited.com (10 characters) without an override gets $3,488 / floor $2,267.
  - **Response.** `s8.bin_cents`, `s8.floor_cents`, `s8.bin_source` (`override` | `ladder` | `grade_price`), `s8.floor_source`.
  - **Expiry.** The closeout case (expiry about a year after the transfer) no longer trips `REGISTRATION_TERM_INVALID`; it trips only after buy date + 2 years + 30 days.
  - **Schedule.** No M6/M18 drops for S8; check `POST /jobs/preview`.
