# Release v2.11.0 (7 Oct 2026)

**Contract:** 2.11.0. Additive (MINOR). CR-011 addendum B: DOM calls the outside reviewer. Founder rule 9 was changed by Dvir (7 Oct 2026, 19:07) to allow this one AI call. **Deploy:** see the end.

## What changed, and how Gavriel tests each item

| Item | What | How to test it |
|---|---|---|
| **Daily review** (T11-16, T11-17, T11-21, T11-26, T11-27) | Daily step `outsideReview` (once per IDT day, weekly on Sunday): builds the packet, calls Google Gemini (`gemini-2.5-flash`), stores the feedback with model and cost. Skips with a reason (`NO_KEY`, `DOCUMENT_MISSING`, `COST_CAP`, `ALREADY_DONE_TODAY`, `TEXT_BLOCKED`) | `GET /jobs/runs?job=daily` → `steps.outsideReview` |
| **Manual run** (T11-21) | `POST /reviews/run` (WRITE, 3 per hour, counts toward the cap) | After Dvir adds `GEMINI_API_KEY` and you upload `company.md`: run it, then `GET /reviews/items` and `GET /reviews/cost` |
| **Honest failure** (T11-23) | A bad key, a refusal, a timeout or a non-JSON answer is stored as `unknown` feedback with Google's status and reason; `/health` `review: "failed"` | Before the key exists: 503 `REVIEWER_NOT_CONFIGURED`, `/health` `review: "not_configured"` |

## Notes
- **Secrets:** `GEMINI_API_KEY` (required for the review) and `GEMINI_MODEL` (optional) are server env only; the key goes in a header, never a URL or a log.
- **Cost:** computed from Google's token counts at $0.30 per million input tokens and $2.50 per million output tokens. Expected under $0.05 a day; cap $5 a month.
- **The guarantee test** (`tests/unit/no-llm.test.ts`) now allows exactly one AI host in one file, and fails on any other.
- **No migration.**
