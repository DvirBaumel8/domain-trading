# Release v5.51.0 (26 Oct 2026)

**Contract:** 5.51.0 (MINOR, behaviour only; no migration, no new fields).

- **What changed:** the auction score v4 is reweighted after the first backtest on our own production labels (`docs/research/backtest-production-2026-10-26.md`: 148 sold, 553 unsold). Other endings of the name with a live site predicted best (AUC 0.78, 0.80 on names aged 5+), age + live endings + exact-match endings together 0.84-0.88, while the name-quality part was near a coin toss. Weights: name 30 (was 70), demand 40 (was 15), age 25 (was 10), bids 5. A name whose other ending has a live site is no longer capped for an uncommon word (foreign and brand words sell). No v4 shortlist was stored before this, so the version stays `auction-v4`.
- **Impact on Gavriel:** the order of the shortlist follows demand and age more; names with no demand get lower maximums and drop out sooner.
- **How to test it:** after the next data save, `GET /auctions/shortlist`: `parts.demand.max` 40, `parts.name.max` 30, `parts.age.max` 25. Tests AS549-2, AS549-10.
- **Deploy:** the Mac host after CI.
- **Lessons:** backtest on our own population before choosing weights: the hand weights of v4 (name 70) were set from the CR-002 seed (hand registrations) and were wrong for expired auction names within a day.
