# Release v2.7.0 (7 Oct 2026)

**Contract:** 2.7.0. Additive (MINOR). CR-010 (fast test runs). **Deploy:** live since 2026-10-07 (`GET /health` `version: 2.7.0`). DOM started the TEST15 rescore again on 2.7.0 as `R15-T15-V2-NOW-B` (it reuses the answers the first run stored).

## What changed, and how Gavriel tests each item

| Item | What | How to test it |
|---|---|---|
| **Reuse with provenance** (T10-4) | Every census sibling and `ext_dates` extension shows `checked_at` and `reused`. A test set takes `max_answer_age_days` (default 7) and its `GET` shows `lookups {fresh, reused, unknown, rate_limited}` and `timing {started_at, finished_at, minutes}` | `GET /selection/test-sets/{name}` |
| **Date safety** (T10-5) | A stored answer is reused for a row's `as_of` only if it was read on or after that `as_of`. With `features_as_of: "now"`, only the age limit applies | A `row` rescore after a `now` rescore of the same names reuses answers (they were read after every `as_of`) |
| **Speed** (T10-1, T10-2, T10-7) | Test-set runs ask each registry up to 4 at a time, 250 ms apart, halving the rate on a 429 or refusal. Stored answers are read in one query per name and never wait | T10-1: rerun `R15-TEST15-USED` on `v11` with `bt1@v2` and `features_as_of: "now"` within 7 days; read `timing.minutes` |
| **Live screening** (T10-6) | Unchanged pacing and freshness. It shares the same answer store | |
