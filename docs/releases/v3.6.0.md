# Release v3.6.0 (9 Oct 2026)

**Contract:** 3.6.0, MINOR, additive. CR-030 (simplified; see the CR).

- **What changed:** `POST /buy` with `small_buy_exception: true`, and Dvir's line naming the domain and containing "small buy", skips the buy hold for that buy. The name must cost at most $11.08 first year (not premium) and fit within $50 of small buys in a rolling 7 days. Everything else is unchanged: the full screening pack, the open tranche, the caps and the approval rules. A real buy needs Dvir present (founder rule 12).
- **How to test it:** dry run `POST /buy` for ukcbamcompliance.com with `small_buy_exception: true`, `dry_run: true` and an `approval_ref` naming the domain with "small buy" → `would_be_blocked` and `small_buy`. Expect `NO_TRANCHE` if the name isn't a member of the open tranche.
- **Migration:** `1762800000000_v3-5-0-b.sql` (`purchases.small_buy_exception`).
