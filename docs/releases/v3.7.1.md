# Release v3.7.1 (9 Oct 2026)

**Contract:** 3.7.1, PATCH, additive. CR-038 #1.

- **What changed:** a `/buy` dry run that ends in an error (for example `REGISTRAR_FUNDS`) now carries `display_name`, `drop_policy`, `renewal_committed_cents` and `drop_policy_line` in `details`, so the buy card shows them even when funds are low.
- **How to test it:** repeat your dry run with `drop_policy: "at_first_expiry"` and read `error.details`.
