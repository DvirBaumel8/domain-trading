# Release v5.44.0 (25 Oct 2026): safety upgrades of the auction pre-bid check and the after-auction transfer check

Contract MINOR. Migration `1766900000000_v5-44-0.sql` (two nullable columns on `domains`). Free sources only (Dvir, 25 Oct 2026); research `docs/research/funnel-names-safety-2026-10.md` section 5.

## What changed (contract)
MINOR release (migration `1766900000000_v5-44-0.sql`: `domains.transfer_confirmed`, `domains.transfer_checked_at`).
- `POST /auctions/prebid`: new checks `BRAND-TYPO-2` (typo, look-alike letters or a contained brand against the Majestic top 10,000 brand labels; FAIL, FLAG when the brand or the name is an ordinary word), `URIBL-1` (black FAIL, grey or red FLAG, a refused or unprovable query a FLAG), `SPAMHAUS-DBL` (always SKIP: free access is non-commercial only), `EUIPO-1` (always SKIP until the founder creates an EUIPO key). Every check has `checked_at`. `manual_required[EXACT_STRING_BUSINESS]` adds `name_as_words`, `camel_case`, `search_strings`; `HIST_WAYBACK` adds `wayback_url`.
- `POST /portfolio/import` (S8): the answer adds `transfer_confirmed` (RDAP's registrar is the one imported into: true / false / null) and a warning `S8_TRANSFER_UNCONFIRMED` when it is not true. `/report` warning `S8_TRANSFER_UNCONFIRMED` (warn) until the daily `portfolioCheck` step sees our registrar. Listing is not blocked.
- New codes in evidence: `URIBL_BLACK`, `URIBL_GREY_RED`. New report warning `S8_TRANSFER_UNCONFIRMED`.


## Impact on Gavriel
- A pre-bid answer has 14 checks instead of 10 (order in `endpoints.md`). Two are always SKIP by design (SPAMHAUS-DBL, EUIPO-1); read their reasons, they are not passes. `BRAND-TYPO-2` can FAIL a name (verdict `fail`, so no bid plan: 409 `PREBID_FAILED`) or FLAG it.
- Paste the strings in `manual_required[EXACT_STRING_BUSINESS].search_strings` into Google for the exact-string check; the plan still needs both manual items confirmed.
- After an S8 import read `transfer_confirmed`. If it is not true, do not list the name; `/report` shows `S8_TRANSFER_UNCONFIRMED` until the daily check sees the name at our registrar. S8 names imported before this release show the warning until their first daily check.

## How to test via the API
`POST /auctions/prebid` with a `.com` name registered elsewhere (a prebid is a stored row; there is no `dry_run`). `POST /portfolio/import` with `dry_run: true` reports `transfer_confirmed` without writing.

## Open items for the founder (Dvir)
- EUIPO: a free API key from the EUIPO developer portal would turn `EUIPO-1` from SKIP into a real check (the call is a follow-up build). Until then search EU marks by hand (TMview).
- URIBL: its datafeed FAQ (https://uribl.com/datafeed_faq.shtml, read 25 Oct 2026) requires the paid feed only "if you provide commercial services which query URIBL" or above 100k queries a day. We sell no service built on it and ask a few names a day for our own buying, so the free public lookups fit. The authoritative servers were not verified live. Until the first live run shows `control_ok: true`, `URIBL-1` is a FLAG (`CONTROL_FAILED`), never a pass.
- Spamhaus has no free commercial access, so `SPAMHAUS-DBL` stays SKIP.
- Tranco is not used (licence, G-30); the brand list is the stored Majestic top 10,000.
