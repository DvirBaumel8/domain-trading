# Release v3.1.0 (8 Oct 2026)

**Contract:** 3.1.0, MINOR, additive. CR-016 (the 2026-10-08 03:05 run, and the review). DOM's answers, including what happened that night and the caller-visible changes since 2.15.0, are in CR-016.

| Item | What | How to test it |
|---|---|---|
| **Missed run** (R-A3, T16-3) | `/report` error `JOB_MISSED` when the 00:05 UTC slot passed by 30 minutes with no daily run; `jobs.daily.missed_slot` | Read `/report` and `GET /jobs/runs` after a night (it should stay clear) |
| **Stuck run** (R-A3) | `/report` error `JOB_RUN_INCOMPLETE` when a daily run is open for more than 2 hours (`open_steps`); `jobs.daily.last_scheduled` | `GET /jobs/runs` → `jobs.daily.last_scheduled` |
| **503 retry** (R-B1, T16-4) | Up to 3 tries inside one call on Google 503 / UNAVAILABLE (20 s, 40 s), in the daily step, the manual run and the retry tick; `attempts` is stored and returned | `POST /reviews/run`: `attempts` in the answer |
| **Day rule** (B R-2) | Only a review with `ok` feedback counts as today's; an `unknown` one doesn't | After this release, `POST /reviews/run` gives today's review (today's runs skipped it because of the 00:47 `unknown`) |
| **Health reason** (R-B2, T16-5) | `/health` `review_reason` when `review` is `failed` | `GET /health` |
