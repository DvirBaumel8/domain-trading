# Release v3.2.2 (9 Oct 2026)

**Contract:** 3.2.2, PATCH (posting fix).

**The cause:** Buffer's live API differs from its published reference. 3.2.1's schema check returned the live definitions:
- `mode`, `schedulingType` and `needsApproval` are required;
- `assets` is a required list;
- an image takes `{url, metadata: {altText}}`.

**What changed:** the `createPost` input is now built from those definitions. The test copy of Buffer's schema (`tests/helpers/buffer-schema.ts`) mirrors the live answer, and it refuses both the 2.12 shape and the 3.2.0 shape.

**How to test:** `POST /posts/schema-check` → `ok: true`, then one real `POST /posts` with a new key.
