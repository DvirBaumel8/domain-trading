# Release v2.16.4 (8 Oct 2026)

**Contract:** 2.16.4. PATCH, **no change visible through the API**. Refactor step R2, part 2.

- **Every source file now lives in a module or the shared core:**
  - `src/modules/{registrars, listing, selection, buying, candidates, selling, reporting, outreach, ops}`;
  - shared code in `src/core/` (now also RDAP, the safe fetch, the nameserver lookup, tokens and the approval check);
  - `src/http/`, `src/db/`, and the app entry files at the top.
- **The boundary test** fails on a file outside this layout, an import into another module's files, or a cycle between modules.
- **The admin and job CLIs** keep their npm names (`npm run admin`, `npm run job`) and now point to `src/modules/ops/`.
- **The data files** (word lists, frozen splits, sibling pools) load correctly from the built `dist/` code.
- **No migration.**
