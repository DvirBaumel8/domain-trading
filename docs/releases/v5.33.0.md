# Release v5.33.0 (21 Oct 2026)

**Contract:** 5.33.0. CR-073a PP-V2: pick-proof two-word rule pickproof-v2 (common words, 3+ letters). MINOR (additive). Migration `1766200000000_v5-33-0.sql`.

## What changed (contract)
- **New recipe `pickproof-v2`, for every pick day frozen from this release on** (the first day whose pool freezes after 5.33.0 is live; the target is 2026-10-23, or 2026-10-22 if nothing froze it before the deploy). Only `is_two_word`, and so the C1 sub-pool, changes. A name is two-word when:
  - its SLD is letters only, at most 10 letters, and not SPELL-1;
  - at least one split into exactly two parts has each part at least 3 letters, containing a vowel (a e i o u y), and on the common-word list.
- **The common-word list:** `data/wordlists/en-scowl-35-lower.txt`, sha256 `60ca88eb55f3738f9a0097e658826c4c1860bbe039069adc2673ce4c1841dc16`, 38,614 words. It is SCOWL size 35, the most common English words, from the same ESDB revision as the existing list. It keeps only the entries the source writes in lowercase: no proper names and no upper-case abbreviations (DHS, AR). The vowel rule removes the one lowercase abbreviation left at this size (`rpm`). The server checks the file against its sha256 on load. The rebuild from the source reproduced the old `en-scowl-60.txt` hash exactly, so the provenance is the same.
- **Results:** `dhsar` → false; `sunbox`, `redcar` → true; `qzxvkw` → false; `goal` (go + al) → false.
- **Manifest `recipe.version`** shows the day's own version, with that version's hashes. Days frozen before keep `pickproof-v1` and their stored flags: their published `pool_rule` hash does not move. The v2 pool-rule text also states the price-tie rule correctly (dynadot before godaddy, G-117) and the `POOL_NOT_READY` condition. `pool_sha256`, the seed and the draw are unchanged.

- The first day frozen after the deploy: `recipe.version` is `pickproof-v2`; in `GET /pickproof/{date}/pool`, `dhsar.com`-like names (if present) have `is_two_word: false`, and the count of `true` is lower than under v1 (5,841 on 10-21).
- Local tests: PP533-1..2 (`tests/modules/pickproof/unit/two-word.test.ts`), PP533-3 (`tests/modules/pickproof/pickproof.test.ts`).

Deploy: pushed to `main` with the tag; the Mac host deploys after CI passes (and runs the migration). Gavriel confirms the live version on `/health`.

**Lessons:** a word list built by lowercasing a dictionary merges abbreviations and proper names into it. Keep the source's casing when a rule needs "real words", and freeze any list a published hash depends on by its own sha256. Version a rule per frozen day instead of changing it in place.
