# Release v5.19.0 (20 Oct 2026)

**Contract:** 5.19.0. The visitor counter runs without approval lines; BUG-045 fixed.

**Deploy status:** pushed and tagged; the Mac host deploys it once CI passes. Gavriel confirms on `/health`.

## Contract changes
- **No approval lines (Dvir, 19 Oct 2026: "you just do it"):** `approval_ref` is optional and ignored on `POST /visits/settings` and `POST /visits/forward/{domain}`.
- **On by default:** the migration sets `visits.enabled` = true and requests the visit-counter token. The Mac host's deploy tick (`visits-token.sh`) creates it and hands it through the GitHub secret to the api-proxy Worker. No call and no person are involved.
- **BUG-045:** `/visits/forward` and `/visits/weekly` decide "on Afternic nameservers" from the **live** nameservers. They fall back to the stored `lander_ns` only when the lookup fails. `lander: "afternic"`, the listing venue of the Porkbun names, no longer counts as Afternic NS.
