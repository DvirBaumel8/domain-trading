## Platform responses (not from the service)

Render's front door (Cloudflare) answers some malformed paths itself, before the request reaches the service. No DOM test can produce these; they were checked live on 2026-10-07 (CR-006).

| Request | Answer | Who answers |
|---|---|---|
| A complete escape that decodes to invalid UTF-8 (`/portfolio/%C3%28`) | 400 `INVALID_REQUEST`, JSON error shape | the service (the tests above) |
| An escape that is not hex (`/portfolio/%ZZ`, `%zz`) | 400, `text/html` Cloudflare page | the platform edge |
| A truncated escape (`/portfolio/%E0%A4%A`, `a%`) | 520, `text/plain` "error code: 520" | the platform edge |
