# Registrar research: which registrars `dt buy` can use

**Checked:** 3 Oct 2026, 18:20–18:40 IDT, from official docs where I could reach them. "UNVERIFIED" means I couldn't confirm it today. `dt` must never treat an UNVERIFIED value as fact: it always uses **live quotes** at buy time, and this table is only for orientation.

**Hard requirements** (a registrar that fails any of these is excluded from the comparison):
- **R1:** A documented registration API, plus an adapter in `dt` that passes its contract tests.
- **R2:** Allows **third-party nameservers**. Without this, the domain can't point at the for-sale lander.
- **R3:** The quote returns a price for **both** the first year and the renewal.
- **R4:** Not a premium or aftermarket price, quoted in USD.

**Soft preferences:**
- prepaid balance (the balance acts as a natural spending limit);
- free WHOIS privacy;
- Afternic Fast Transfer support.
